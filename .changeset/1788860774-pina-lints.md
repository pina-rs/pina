# add the deny_unused_account_borrow_guards lint

New warn-level lint flags account borrow guards bound to locals that are never read, with a machine-applicable multipart fix that discards the guard immediately (as a `?` statement, with the orphaned `drop(local);` removed in the same edit). Fix mode now attaches the lint driver through `RUSTC_WORKSPACE_WRAPPER` because the `cargo fix` proxy bypasses `RUSTC_WRAPPER` for primary units.
